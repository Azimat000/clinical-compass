# Три блока интерфейса — код без проверок, 27.10.2026

Прямое поручение: продолжить подключение трёх блоков без проверок, сохранить
всю историю, существующий стиль и навигацию, остальное не менять, максимально быстро.
Это разрешает совместную подготовку FE05–FE08, но не означает приёмку этих срезов.

Добавлены локальные блоки dashboard/doctor_patient/decisions, отдельные CSS/JS.
Таблица, фильтры, навигация, прежние формы, история и подтверждённый план сохранены
в исходных шаблонах. Общие app.css/base/doctor_base не менялись.

Код использует существующие API alerts/analyses/diagnosis-review/plan-reviews:
- сигналы: чтение, версии/основания, исходные снимки, страницы, явные received/seen/processed;
- диагноз: ведущая гипотеза/альтернативы, исходные сведения, состояния/история,
  отдельный ручной диагноз врача с основаниями/неопределённостью и серверной версией;
- план: сохранённые предложения/проверки лечения, выбор пунктов и сроков,
  подготовка редакции через BE15, переход к прежнему отдельному подтверждению.
  Лекарства/направление остаются через существующий ручной редактор: новый
  структурированный редактор BE14/BE15 не завершён.
- чтение каждые 30 секунд, скрытая вкладка останавливает опрос; чтение не запускает
  генерацию. Генерация только явной кнопкой, серверные ограничения не отключены.
  Координатор автоматической генерации FE06/07 не реализован.
- текст врача не заполняется моделью и не заменяется опросом. Повторы используют
  прежнее тело/ключ; 409 оставляет текст и требует обновить серверные основания.

Новые read-only endpoints decision-support проверяют наличие таблиц и настройки
очереди; plan-review-state читает текущую версию для BE15 после авторизации.
Нет миграции, записи клинических событий/назначений, seed/reset, модели или расходов.
Рабочая база015, рабочий8000/worker и замороженная runtime-копия НЕ переключены.
Поэтому изменения пока в исходном коде, не на работающем сайте. На базе015 новый
клиент покажет отсутствие подключения; для содержательных результатов требуются
отдельное включение подготовленного backend и завершение FE03B/C.
