## Изменения и доказательства

Единый apps/compass/backend_model.py: реальный HTTPS DeepSeek, только flash,
thinking отключён, JSON mode и независимая проверка схемы, ограничение входа,
ответа, времени и расходов. Есть отмена локального ожидания, безопасные коды
ошибок и отдельный устойчивый SQLite-бюджет. Автоматических повторов нет.
Нет полномочий назначать, применять план или создавать клинический ready.
Новых зависимостей и миграций нет. docs/architecture/backend-model.md описывает
настройку, ограничения и восстановление. tools/model_smoke.py читает только
встроенные вымышленные данные и локальный ключ 0600, не медицинскую БД.

По исследованию официальных источников выбран deepseek-flash. Отчёт с URL,
ценами, Terms/Privacy и пределами — evidence/BE04/research.md. Идентификатор API
не является неизменяемой ревизией весов; API её не предоставляет. Инструкция
compass-model-v1, хеши инструкции и схемы сохранены вместе с фактическим ответом.
Каталог источников backend-sources-v1/срок BE03 не менялись. Клинический выпуск
остаётся blocked: реальные чувствительные данные DeepSeek не передаются.

Первая попытка остановилась до отправки на недостающем CA Python; причина
проверена отдельным TLS connect без ключа. Исправлено загрузкой системных
корней macOS, проверка сертификатов не отключалась. Вторая попытка со старым
ключом окружения получила реальный HTTP 401. После прямого поручения пользователя
новый ключ сохранён в локальном var/deepseek-api-key (0600, ignored) и принят.
Неудачные попытки сохранены отдельно, итог не заменяется ими.
