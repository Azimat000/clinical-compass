## Реализованный результат

risk-candidates-v2 / be08-context-v2: компактное кодирование полного контекста
четырёх источников без обрезания/потери пустых полей. Инструкция исправлена до
контрольного вызова: разные даты и историческое отрицание не discrepancy.
Сервер дополнительно требует две цитаты и одну известную дату для discrepancy.
Неверные цитаты/поля/типы/даты/добавленные клинические утверждения отвергаются.
Точная цитата не объявляется клинически истинной. Отрицания, семейный анамнез,
команды в данных, пропуски и причинность остаются явно ограниченными.

Новая ветвь существующего executor работает только при enabled=1 и
 generation_version=be08-context-v2 в синтетической БД. Модель вне транзакции;
lease/token/отмена/текущий доступ/свежесть проверяются перед публикацией.
В общем SAVEPOINT/транзакции сохраняются проверенные эпизоды, оценка и версия
анализа, затем завершение задания. Проверен полный откат при сбое последнего
UPDATE. Новых таблиц/миграций/зависимостей нет. По умолчанию disabled.

Result содержит неизменный воспроизводимый BE07, модель не может его отменить.
Непроверенные кандидаты отдельно: optional Analysis.risk_context и врачебный
GET/HEAD /api/v1/patients/{patient_id}/analyses/{run_id}/risk-context.
Partial/not_established/clinical_ready=false сохраняются при любом исходе.
Недостаточные правила могут сосуществовать с отдельными непроверенными
кандидатами; положительное правило сохраняется при сбое/лимите/пустом ответе
модели и ошибке инициализации адаптера/бюджета. Актуальные права и та же связь
проверяются при чтении, stale явно обозначен, no-store, побочных действий нет.
