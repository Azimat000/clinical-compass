# UI13 · только текущий план · 27.10.2026

Прямое поручение: показывать пациенту только пункты текущего плана, старые
задания и ответы перенести в закрытую раскрываемую историю.

В plan_tasks.view добавлен is_current по action_id последнего подтверждённого
решения (therapy_stop не имеет действующих пунктов). Старое superseded учитывало
дату и ошибочно оставляло на главной просроченные пункты предыдущих версий.
Пациентская форма теперь только для is_current; остальные задания, последний
ответ и все предыдущие ответы доступны в «Истории заданий и ответов». Сервер
отклоняет новую запись из устаревшей вкладки, а повтор уже сохранённой операции
остаётся идемпотентным. Исторические данные и экран врача не удалялись.

Проверено основным агентом: 31 тест plan_tasks/communication PASS, включая
прошлое задание с ответом, закрытую историю без формы, отказ старой вкладке и
новый план без заданий. Рабочий8000: Chromium390/1440 — 2текущих/7исторических,
история закрыта при входе, раскрывается, форм в ней нет, переполнений нет.
Доказательства evidence/UI13/tests.log, browser.json, partition.json.
Физический телефон и полная регрессия не проверялись. Тег interface/UI13.
