## Локальное демо S07

Создан каркас приложения: шесть синтетических случаев, поиск/фильтр, база данных и обработчик технических событий. Запуск: `make setup migrate seed`, затем `make run`; в другом терминале `make worker`. Проверки: `make check`. Есть запуск через Docker Compose; полная инструкция — [RUNBOOK](docs/RUNBOOK.md).

В S05 добавлены вход, раздельные кабинеты, одноразовые приглашения и проверка связи. После seed создайте локальные случайные пароли командой seed-accounts по RUNBOOK; до принятия приглашения карточка врачу недоступна. В S06 работают самоотчёт пациента, визит врача, история и отдельные факты/НЯ с источником; неизвестное и противоречия явно видны. В S07 добавлена точная DASS-42 в закрытом синтетическом режиме: врач предлагает анкету, получает исходные ответы/три суммы/историю; пациент получает квитанцию и отдельно видит график своего дневника. Диагнозы/лечебные правила не активируются, клиническая апробация ещё не проведена. S00–S07 принимают только результаты своих карточек, не все условия продукта. Актуальный следующий срез — в STATE. Локальный репозиторий не опубликован. Клиническое внедрение требует отдельных разрешений и доказательств.
