## Отключение и восстановление

Остановить каждый из трёх собственных терминалов Ctrl+C; не трогать процессы8000.
После остановки worker выключить настройку копии:

```sh
.venv/bin/python - <<'PY'
from apps.compass.db import connect
db=connect('var/FE02-integration.sqlite3')
db.execute('UPDATE backend_job_settings SET enabled=0')
db.close()
PY
```

Прерванные задания сохраняют lease90s и bounded retry≤3; после перезапуска
восстанавливаются штатной очередью. Не править результаты/lease/попытки вручную
ради зелёного состояния. Без worker результат не обновляется сам.
Отключение копии не откатывает данные или расходы. Если код надо исправить —
новый коммит, без reset/перемещения тегов/восстановления старой рабочей базы.
