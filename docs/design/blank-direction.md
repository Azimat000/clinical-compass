# Интерфейс «Бланк»

Выбрано пользователем 21.10.2026 из трёх макетов («Бланк», «Линия между приёмами», «Дневник»). Это решение по оформлению, не медицинское заключение и не проверка пользователями.

## Идея

Интерфейс строится из языка русских клинических бланков и анкет: структурные линии, подписи под линией, ряды кружков для ответов, журнал вместо набора карточек. Памятка по смыслу — как у бумажного опросника, который заполняют ручкой: ясно, что отметить, и видно, что записано. Не добавлять карточки с одинаковыми скруглениями, цветные плашки-ярлыки, градиенты, тени, строки через точку, заглавные надписи над заголовками и нумерацию там, где нет настоящей последовательности.

## Цвет (все пары текста — не ниже 4,5:1 по расчёту WCAG)

| Роль | Значение | Использование |
|---|---|---|
| Чернила | #1c1e26 | основной текст, линии заголовков |
| Бумага | #fbfbfd | фон страницы, поверхность |
| Синие чернила | #2342b5 | ссылки, главное действие, выбранный ответ |
| Печать | #b8232c | критический сигнал, «Обязательно» |
| Вторичный | #5a5f6e | подписи, пояснения |
| Линия | #c5c9d6 | тонкие разделители |
| Предупреждение | #7a4a00 на #fff4dc | требуется уточнение |
| Фокус | #b57600, обводка 3px | видимый фокус клавиатуры |

Состояния различаются словом и формой, не только цветом: «Обязательно» — сплошной квадрат, «Желательно» — пунктирная рамка, «Неизвестно» — круг со знаком вопроса.

## Шрифты

PT Serif (заголовки, коды пациентов) и PT Sans (текст, формы) — Paratype, лицензия OFL, русский алфавит из коробки. Файлы лежат в apps/compass/static/fonts (PTSans-Regular, PTSans-Bold, PTSerif-Bold, тексты OFL рядом), скачаны 21.10.2026 с согласия пользователя; происхождение и sha256 — docs/design/fonts.lock.json. Внешние службы не используются. Символы ⚠ и ◇ в шрифтах нет, их показывает системный шрифт.

## Композиция

Верхняя панель с двумя-тремя разделами для каждой роли, без боковой колонки. Заголовок страницы называет задачу («Кому нужно внимание»). Списки пациентов — журнал-таблица с подписями столбцов под линией; поля ввода — линия с подписью под ней; шкалы ответов — ряды кружков с подписью столбцов. Подтверждение, проект, получение и реакция врача остаются отдельными словами. Существенные ограничения (синтетическое демо, не экстренная помощь, отсутствие записей не означает отсутствия риска) остаются видимыми.

## Границы

Клинические тексты, DASS, правила, роли, CSRF и серверное подтверждение врача оформлением не меняются. Стек: Flask/Jinja, CSS, обычный JS. Новых зависимостей нет.
