# Навыки интерфейса: порядок работы по срезам

Этот набор установлен для HAC в `.agents/skills/`, хранится вместе с проектом и не меняет глобальные навыки других проектов. Точные исходники, закреплённые версии, лицензии и контрольные суммы — `skills.lock.json` в этой папке. Входная точка — `$hac-interface`.

## Где применять

| Срез | Работа с интерфейсом | Что должно остаться как доказательство |
|---|---|---|
| S13 | Дизайн, сценарии двух ролей, адаптация, доступность, поиск и фильтры. Основное место применения набора. | Исходные и итоговые снимки, принятые решения по компонентам, реальные проходы задач, браузеры/версии, время и действия. Отдельно доказательства индексов/расширяемости из исходной карточки. |
| S14 | Проверка ошибок, отказов доступа, истечения сеанса, повторной отправки, текстов подтверждений после визуальных изменений. | Отрицательные сценарии и серверные проверки; красивый экран не доказывает защиту. |
| S15 | Проверка влияния CSS/JS/ресурсов на измеренную скорость. | Фактические измерения на указанной машине и среде; оценка «на глаз» не заменяет замер. |
| S16 | Задания и наблюдение за действительными пользователями; точечные исправления по замечаниям. | Условия, участники, результаты и ограничения. Проход агента остаётся самопроверкой. |
| S18 | Визуальная согласованность работающего демо, слайдов и постера. | Снимки существующего приложения, реальные сценарии и отдельные правила артефактов. Навыки интерфейса не заменяют навыки презентаций/PDF. |
| S20 | Исправления по подтверждённой обратной связи предзащиты. | Связь каждого исправления с замечанием, повторный проход изменённых задач. |

Не запускать соседние срезы одновременно из-за этого документа. Предыдущие результаты S04–S12 служат исходным состоянием; их приёмку и клинические ограничения не переписывать. Установка навыков не закрывает требования E03/T04/T08/M06 и не является принятием S13.

## Как начать следующую сессию

> Выполни только S13 по START_HERE.md. Для интерфейса используй $hac-interface и docs/design/interface-direction.md; исходники навыков лежат в .agents/skills. Сначала оцени текущие экраны и сценарии обеих ролей, затем реализуй цельный интерфейс и проверь его в доступных браузерах. Сохрани клинические различия, серверные подтверждения врача и все остальные работы S13. Запиши доказательства и ограничения, обнови память, сделай коммит и тег только по фактической приёмке.

Навыки из `.agents/skills/` предназначены для обнаружения Codex в контексте проекта на следующем ходе. Если каталог не появился в списке навыков клиента, прочитать локальный SKILL.md по указанному в AGENTS.md пути; повторная установка или глобальное копирование не требуется.
