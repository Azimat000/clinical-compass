# BE04: синтетическое подключение DeepSeek API

Пользователь 26.10.2026 выбрал временно DeepSeek по API. Один внутренний адаптер
`apps/compass/backend_model.py`: DeepSeek(Config(model='deepseek-flash'), Budget(path)).
`generate(data, schema, synthetic=True, cancel=threading.Event())` возвращает value
и технические metadata либо ModelError с безопасным кодом. Это не четвёртая
продуктовая функция. Будущие BE05/06 подключают извлечение/очередь; три
клинические функции и готовность ready этим срезом не реализуются.

## Контроль

- Единственный реальный адрес HTTPS api.deepseek.com/chat/completions; нет
  redirects, tools, SDK, retry, web search, загрузки файлов или чтения БД пациентов.
  Только deepseek-flash, thinking disabled, temperature=0, stream=false.
- До сети: явное synthetic=True; проверка ключа, длины входа, контекста и
  максимальной стоимости. Это подтверждение вызывающего кода, не автоматическая
  анонимизация. Не передавать реальные/обезличенные клинические записи.
- Инструкция compass-model-v1: вход — данные, не команды; без выдуманных фактов
  и ссылок/действий. Это дополнительное ограничение, не доказанная защита от всех
  prompt injections; содержательная проверка фактов/цитат ещё BE05/16.
- Двойная проверка JSON: дубли/NaN/некорректныйUTF8 отклоняются; затем локальная
  схема конечного подмножества backend_analyses.validate_schema. Неверный формат,
  отказ/tool call, обрезка, неверный usage, превышение ответа дают ошибку.
- Лимиты Config:12000 байт вход/system/schema,256 output,128 КиБ ответа; timeout30 с.
  Smoke: 128 output/60 с. Поток ожидания ограничивает время вызывающего кода даже
  при keep-alive; отмена проверяется до/во время/после ожидания. После отмены или
  timeout сетевой daemon может ещё завершаться. Это отмена локального ожидания,
  не гарантия остановки вычислений/списания поставщика. Повторов нет; резерв
  сохраняется. Результат после локальной отмены не публикуется и не сохраняется.
- Секрет и клинический текст не попадают в обычные логи/ошибки. Ошибка HTTP
  обрабатывается по статусу без чтения текста поставщика в сообщения пользователю.
- TLS проверяется всегда. НаmacOS Python.org без OpenSSL CA загружаются системные
  корневые сертификаты через фиксированную /usr/bin/security; verify не отключается.

## Расходы

Budget — отдельныйSQLite-файл 0600, не медицинская БД; BEGIN IMMEDIATE атомарно
резервирует худшую стоимость. Вход оценивается UTF8-байтами + 512 на обрамление,
выпуск — max_tokens; потолки $1/$5 за миллион выше проверенного тарифа flash.
Общий накопительный лимит $0.05 и один вызов ≤$0.02, без дневного сброса. Ledger
нельзя удалять ради обхода лимита. После успешногоusage резерв заменяется
консервативной измеренной оценкой; неизвестный исход сохраняет резерв. Нет
автопополнений/покупок. Отдельный процесс/инойledger не является глобальным
ограничением аккаунта DeepSeek. Это лимит данного подключения.

metadata сохраняет input/output/total и cache hit/miss, две тарифные оценки,
консервативную сумму, ID модели, версии/hash инструкции/schema и время.
Фактический счёт поставщика и курс RUB неизвестны, USD-оценка не называется
подтверждённым рублёвым расходом. Источники/тарифы/приватность —
`evidence/BE04/research.md`. Новая оценка понадобится при изменении тарифов.

## Настройка и ручная проверка

Адаптер читает DEEPSEEK_API_KEY из окружения процесса. Изолированный smoke также
умеет читать локальный `var/deepseek-api-key` (0600) и задаёт ключ только внутри
своего процесса, с приоритетом над прежним окружением. Этот файл создан по
прямому поручению пользователя, игнорируетсяGit. Ключ не переносится всистемное
окружение/браузер/рабочий сервис. Тестовый бюджет — `var/deepseek-budget.sqlite3`.

```sh
.venv/bin/python tools/model_smoke.py --output var/deepseek-smoke.json
.venv/bin/python -m unittest apps.tests.test_backend_model -v
```

Smoke использует только встроенный явно вымышленный текст/схему, не принимает
путь к базе/пациенту. Проверяет точное число дней и сохранение diagnosis=null;
ошибка качества завершаетсяexit1, неready. Конфигурация запуска: flash, 128 output,
12000 байт входа,60 с, 0.05 USD общий потолок. Более широкое клиническое качество
требует будущих срезов иBE19. Фактическое доказательство —
`evidence/BE04/live-smoke.json` (test_double=false); модульные заменители всегда
получаютtest_double=true. У модели нет полномочий применить план/назначение.

Рабочий сервис 8000/worker/учётные данные и медицинская БД не менялись и не
перезапускались. Миграций/зависимостей нет. Возврат — прежнийGit-код, приостановка
новых ручных вызовов; секрет/ledger остаются внеGit, повторять вызовы для отката
не нужно. Клиническийrelease остаётсяblocked; источникBE03 истекает отдельно.
