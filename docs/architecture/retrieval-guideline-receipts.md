# Квитанции двух дополнительных КР

21.10.2026, частичный результат B03B. Это источниковый допуск, а не принятие
B03B/B03/B, готовность поиска или независимое клиническое заключение.

В retrieval_primary.py отдельная закрытая ветвь допускает только KR456_3
«Паническое расстройство» и KR451_3 «Шизофрения», с точными официальными URL.
Тип остаётся clinical_guideline. Политика guideline-source-policy.json отделена
от шести идентичностей DASS и их primary-source-policy.json. Клиническая КР
не может заимствовать привязку к ресурсу DASS, тип инструмента или его права.

original_storage=verified_guideline_receipt означает собственный JSON
с квитанцией: URL, версия, SHA полученного PDF, время, MIME, размер,
физический локатор и SHA отчёта проверки. Отдельный receipt_sha256 связывает
именно локальную квитанцию; она не выдаётся за сохранённый оригинал.
Никакого сетевого получения в импорте или поисковом запросе нет.

Две квитанции и по одному самостоятельно изложенному факту находятся в
зарегистрированном J02B03B-пакете. Только paraphrase экспортируется для индекса.
Полные PDF/HTML, страницы, OCR, таблицы, вопросы и новые цитаты не допускаются.
Права, атрибуция, контекст и малый объём каждого точного JSON имеют отдельное
решение B03B. Любой другой источник, URL, тип или представление этим не разрешён.

При каждом чтении заново проверяются закрытая идентичность, пины, квитанция,
отчёт внешней проверки, права, сроки и SHA карточки. Отзыв, просрочка, подмена
или отсутствие подтверждённого TLS исключают материал даже из старого снимка.
Импорт публикует новый неизменяемый снимок; старые источники/снимки не перезаписывает.

Составной D09-depression-differential связывает KR301_3-F10 с двумя новыми
фактами: панические проявления оцениваются в контексте депрессии/БАР, а
психотическая граница уточнена только для F20.0–F20.3 и хронологии G1.1/G1.2.
Это справка о границах врачебной оценки, без диагноза по анкете или переноса
оснований лечения. Числовая возрастная граница КР не выводится из adult=true.
Собственные ограничения HAC по-прежнему имеют отдельные policy_references.

Точные источники, новая проверка, ограничения и отрицательные случаи —
evidence/S17J02B03B/research.md, source-review.json, content-review.json,
rights-decision.md, verification.json и apps/tests/test_retrieval_guideline_receipts.py.
Неполные возрастные аспекты русской DASS и все досье сохраняют общий NOT_READY.
