# Решение о технологиях сервиса

21.10.2026, пересмотр ADR FU-AI-01 по прямому поручению пользователя.
**RAG не является обязательной частью сервиса или условием реализации S17I.**

| Задача | Текущий выбор |
|---|---|
| Роли, ведущая связь, доступ, возраст, подтверждение действий | Серверные проверки |
| Точная DASS, полнота ответов и арифметика | Проверенные алгоритмы; клиническая интерпретация отдельно |
| Самоотчёты, дневник, выполнение и нежелательные явления | Структурированные записи с датой/автором/источником |
| Повторный приём | Сводка существующих фактов S17I01 |
| Проекты клинических действий | Версионированные источниковые правила после независимой клинической проверки; пока не активированы |
| Навигация по справочным основаниям | Точные карточки и ссылки; поиск при конкретной потребности |
| RAG, генерация и семантическая модель | Необязательная отложенная ветка, новое прямое поручение и проверка пользы перед возвратом |

Подробный текущий маршрут и источниковые проверки — service-path.md.
Сведения, которых нет, не восстанавливаются из памяти модели. Врач принимает
диагноз/дозу/срочность и отдельно подтверждает клинические действия. Отказ
или отсутствие подсказки не является оценкой безопасности.

## Сохранённые результаты и ограничения

Прежние проверки извлечения literal-v2, их измерения и пределы независимости
сохранены в evidence/S17H/extraction-regression.json и отчёте memory/sessions/S17H.md.
Они не доказывают точность произвольной истории или клиническую полезность;
B15 остаётся. Существующие источник/версия/страница/права/срок/отзыв/приватность
и независимая врачебная проверка обязательны для применимых функций.

Прежнее требование сначала завершить всю RAG-программу было внутренним
архитектурным решением, а не условием исходных 83 требований. Пользователь
отменил его 21.10.2026. Старые решения, принятые срезы и исходные ограничения
сохранены в Git и plan/optional-rag.json, неполное не объявлено принятым.

Новых моделей, библиотек или внешних API этим решением не подключается.
Flask/Jinja, CSS/обычный JS, SQLite и существующий стек сохраняются.
Никакой передачи закрытых материалов или пациентских данных не разрешено.
Разработка Codex и ИИ внутри продукта — разные вопросы. Отсутствие RAG само
по себе не подтверждает медицинскую безопасность или выполнение E02/E06.
