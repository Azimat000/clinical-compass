# Основной путь сервиса без обязательного RAG

21.10.2026. Это текущий план, а не заявление о готовности будущих функций.
Основание — прямое поручение пользователя убрать RAG из обязательного пути.

## Функции

1. Пациент вводит сведения в существующие формы; сохраняются автор, дата,
   исходное содержание, пропуски и противоречия.
2. Врач получает единую сводку повторного приёма за выбранный период и переходит
   к исходным наблюдениям, анкетам, подтверждённому плану и отметкам выполнения.
   Новая сводка S17I01 только читает факты. Существующие отдельные графики
   не выдаются за новую реализацию.
3. Клинические проекты S17I используют проверенные версионированные правила
   после фактической независимой проверки точной версии. Отсутствующее основание
   означает недоступность конкретного проекта, а не безопасное состояние пациента.
4. Врач рассматривает проект и отдельно подтверждает назначение/изменение/отмену,
   направление или изменение плана через прежний серверный механизм.

Точные расчёты DASS, роли, возрастные проверки и независимый критический путь
сохраняются. Пациент не получает вычисленных сумм/интерпретации. Ни сводка,
ни поиск не создают медицинское решение. S17I01 не принимает клинический S17I.

## Проверки источников

Для каждой активируемой функции/утверждения требуется её собственный комплект:

- точный первоисточник, тип документа, версия/официальный статус, URL и страница;
- популяция/возраст, показание и необходимый контекст, включая ограничения;
- правомерное представление и атрибуция; факты и цитаты различаются;
- актуальная проверка сроков, целостности, отзыва и соответствия фактическому выпуску;
- для клинического правила — независимая проверка именно этой версии и сценариев.

Сохранены retrieval_corpus/packages/primary/policies, реестры, квитанции,
история снимков и отрицательные тесты. Менять их из-за смены плана не нужно.
Новый препарат требует источников ГРЛС для конкретной поддерживаемой функции;
сведения о классе, сайт производителя или один листок не заменяют нужный документ.
Неизвестный возраст русской валидации DASS не становится известным.

Полные 58 вопросов/224 аспекта/9 досье/90 разделов были внутренней областью
отдельной поисковой программы. Frozen-файлы и честный NOT_READY сохранены,
но это больше не глобальный барьер для всех функций сервиса. Исходные F/M/E/T/C
и реальные доказательства их выполнения остаются обязательными. Область
конкретной клинической функции нельзя урезать молча ради зелёной проверки.

## Необязательное расширение

Удобный справочник и обычный поиск по допущенным карточкам могут добавляться
по конкретной потребности врача. Семантический поиск и генерация текста
не нужны для выполнения текущего плана и не включаются автоматически.
Прежний план сохранён в plan/optional-rag.json; возвращение требует нового
прямого поручения и отдельной оценки пользы, прав, ресурсов и качества.

Следующий срез — S17I01. Flask/Jinja, CSS/обычный JS и текущие зависимости
сохраняются. Настоящая сессия меняет только план; реализация — в следующей.
