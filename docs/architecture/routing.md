# Ручная маршрутизация — незавершённый S09

Только синтетика. routing-reference-v1.json хранит версию, источники, пределы и неактивные A01–A05. `routing.reference` отказывается работать при попытке включить active_rules. Это запрет непроверенной активации, не готовый движок алертинга. Автоматического выявления ситуаций F08/M05 нет.

Врач любой специальности в «Решения врача» выбирает «Направление», отдельно указывает категорию и срочность. Обязательны описание тяжести, состояние данных, популяция/возраст, источник/раздел/связь с данными и резервный порядок. Эти тексты вводит врач; приложение не утверждает их клиническую правильность. Неизвестное/противоречие сохраняется буквально. Отсутствие категории/срочности не превращается в «желательно/планово». Проект можно сохранить при неопределённости, подтвердить при неизвестной категории/срочности/популяции нельзя.

Справка относится к взрослым. Перед подтверждением сервер сверяет указанный возраст18–120 с исходным профилем, всеми известными источниками и действующей явной сверкой врача через ages.verify. Новые записи/день/источники/связь/план проверяются прежним снимком decisions.snapshot; новая справка маршрутизации — SHA256 из неизменяемого payload. Это техническое ограничение демонстрации; неизвестный возраст не означает низкого риска. Детские алгоритмы не добавлены.

Направление становится записью плана только после отдельного решения действующего ведущего врача. Сохранение/подтверждение/аудит атомарны; повтор не дублирует действие; новая информация требует новой редакции. Старые подтверждённые направления сохраняются. Прежний неподтверждённый проект без routing_review требует новой версии, отклонить его можно. Схема БД/прежние миграции/исторические источники не менялись.

В списке и карточке показаны три последние версии направления с буквальными категорией, срочностью и состоянием. Это история, не текущая оценка риска. «Обязательно» выделено также значком/цветом, «Желательно» — отдельным значком/текстом. Старые записи без полей помечены явно. Пациент видит только подтверждённые тексты и категорию/срочность; внутренние оценки и снимки скрыты. Отдельная форма терапии/её предупреждения сохранены.

Реальных критических событий, срочной доставки, SLA, внешнего резервного канала и согласованного клинического протокола нет. Модуль events и очередь не изменены; S10 не выполнен. Полный S09 BLOCKED по точным оставшимся условиям: evidence/S09/acceptance.md и external-check.md. Следующий независимый срез по текущим зависимостям отсутствует.
