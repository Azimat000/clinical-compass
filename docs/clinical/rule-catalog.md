# Каталог правил: неактивные карточки для проверки

Версия 0.1 от 18.10.2026, S02. **Все R01–R19: `active=false`, `status=draft_inactive`.** Приложение ещё не реализовано; это реестр для S03/S07–S11, не исполняемый алгоритм. Ни одна приведённая кандидатная логика не подтверждает выполнение F01–F08/M01–M10. Медицинские значения, дозы и пороги из памяти не внесены.

## Обязательная карточка и общие значения

Каждый R-ID ниже наследует эти поля. Колонки таблицы и пояснения задают различия. При переносе в приложение S04/S07 каждое поле хранить явно, а не подразумевать из этого документа.

- `id`, `version=0.1`, `active=false`, `status=draft_inactive`; название и назначение — в строке.
- Популяция: только подтверждённая в конкретном источнике; общий возраст конкурса не уточнён. Для кандидатов взрослых источников требуется известный возраст и совпадение с границами конкретного инструмента. Возраст <18, неизвестный возраст, противоречивые даты — отдельные контрольные входы; не общее основание применять любое взрослое правило.
- Входы: значения, единицы, происхождение, время события/приёма, автор, степень проверки врачом. Срок пригодности данных пока не утверждён; не назначать его произвольно.
- Источник/раздел/версия/дата проверки: [sources.md](sources.md), 18.10.2026. Непроверенный раздел отмечен явно; ссылка на каталог не заменяет чтение документа.
- Исключения: выход за популяцию, отсутствующее основание/права, неизвестные или противоречивые входы, неподтверждённая версия источника, непроверенный срок пригодности. Результат — «недостаточно подтверждённых оснований», а не «риска нет». Это техническое состояние, не медицинская оценка.
- Результат: только проект/справка врачу с использованными входами и версиями. Маршрут/срочность не заданы, кроме кандидатов R11–R16, для которых они также требуют утверждения. Пациент не получает неподтверждённый план.
- Действие: назначение/изменение/отмена терапии, направление и изменение плана требуют отдельного подтверждения уполномоченным врачом **на сервере**. Балл шкалы не диагноз. Решение вне инструкции система автоматически не предлагает.
- Автор карточек: подготовлено Codex для проекта; клинический автор/проверяющий не назначены, подпись отсутствует (B04). Дата пересмотра: 19.10.2026 и обязательно до активации, затем перед S16/S17; это контрольная дата, не срок действия источника.
- Проверки ниже — **будущие**, не выполненные тесты. Для каждого набора требуется независимый ожидаемый результат от проверяющего; самописный пример не подтверждает клиническую безопасность.

## Условия передачи зависимым срезам

После принятия S02 срез S03 может готовить технические синтетические входы с явным статусом «клинический эталон не утверждён», но не приписывать этим карточкам экспертную проверку. S07 требует сверки формы, валидации, популяции, подсчёта и прав. S08 требует действующей инструкции ГРЛС для каждого включаемого препарата. S09 требует действующих полных КР и научного основания обоих маршрутов/критических условий. S10 реализует доставку только после определения условий и протокола; надёжная очередь не заменяет клиническую проверку.

До снятия соответствующих B-ID значения доз, клинические пороги, активные формы/правила, готовые тексты срочной помощи и утверждённые медицинские эталоны отсутствуют. Источник с истёкшей/непроверенной актуальностью не переводится в active. Для активации сохранить источник/раздел, результат независимой проверки, имя/роль проверяющего, дату и контрольные случаи в последующем срезе. Общий реестр не служит медицинским допуском.

## Проверенное научное основание и незавершённое отображение

Полные SRC03/SRC04 прочитаны исследователем. Разделы об оценке риска, наблюдении и стационаре перечислены в evidence/S02/research-clinical.md. Они позволяют обосновать необходимость врачебной оценки в R11–R16. Однако конкурсные категории «обязательно»/«желательно», автоматическое условие, входные признаки/давность и срочность ещё не утверждены; сами разделы КР не становятся готовыми активными правилами. Приложение Г4 SRC04 с C-SSRS не включено отдельной шкалой: его русская форма/валидация/права для продукта не проверены. Числовые пороги из него не перенесены.
