# Первый приём у терапевта — проект протокола S17B-v1

19.10.2026. Статус: источниковая спецификация для синтетической разработки; clinical_validation=false, новые правила active=false. Не утверждённый регламент оказания помощи. Главный демонстрационный сценарий — терапевт; в приложении сохраняются общая роль врача и отдельная роль пациента. Начало приёма не требует кода диагноза, F41.1, назначения или заполненной шкалы. Сохранение записи не подтверждает клиническое решение.

## Основания и область

S301: КР «Депрессивный эпизод, рекуррентное депрессивное расстройство», 301_3, 2024 v3, взрослые, [карточка](https://cr.minzdrav.gov.ru/view-cr/301_3), [официальный PDF](https://apicr.minzdrav.gov.ru/api.ashx?id=301_3&op=GetClinrecPdf). S457: КР «Генерализованное тревожное расстройство», 457_3, 2024 v3, взрослые, [карточка](https://cr.minzdrav.gov.ru/view-cr/457_3), [официальный PDF](https://apicr.minzdrav.gov.ru/api.ashx?id=457_3&op=GetClinrecPdf). Текущий внешний контроль и дополнительные источники: evidence/S17B/external-check.md. Локальные архивы evidence/S09/completion-review/sources/kr301.pdf и kr457.pdf прямо прочитаны основным агентом в относящихся разделах.

КР относятся к определённым заболеваниям и популяциям, а не валидируют нашу форму первого визита. Сбор сведений до диагноза — проектная адаптация, требующая проверки B04. Рекомендации для уже диагностированного эпизода не превращаются в обязательный автоматический перечень действий каждому пациенту терапевта. Источники не дают единого балла риска, категории направления и срочности для всего смешанного первого обращения.

## Обязательные данные записи и состояние факта

Минимум для сохранения: действующая связь и права пользователя, идентификатор приёма, тип «первый/повторный», дата наблюдения, источник/автор и хотя бы жалоба либо явная отметка «сведения пока не собраны». Время серверного приёма отдельно. Это техническая политика, не медицинский минимум достаточности. Неизвестный возраст допускает черновик, но не допуск к инструменту/лекарству. Даты в будущем/неверные значения проверяются отдельно; конфликт не исправляется выбором удобного значения.

Каждый клинический факт: собственное значение/текст, «есть / явно отрицается / неизвестно / противоречие» там, где применимо, источник (пациент / запись врача / документ / результат инструмента), дата наблюдения и внесения, версия. Несовместимые утверждения сохраняются оба; врачебное уточнение — новая запись с основанием. Пустая строка не означает «отрицается». Внешний текст/импорт не переносится автоматически в подтверждённые факты (B15).

## Ветви без заранее установленного диагноза

| Ветвь | Данные и основания | Допустимый проект / что блокирует вывод |
|---|---|---|
| Депрессивные жалобы | V02–V09; S301 §2/§2.1 | Сводка и уточнение; S301 рекомендует первичную консультацию психиатра для диагностики. Терапевтическая форма не подменяет её. Точные категория/срочность в новом пути требуют S17D/B04 |
| Устойчивая тревога | V02–V10; S457 §2.1 | Уточнение длительности, трудно контролируемой тревоги, других причин; без F41.1 и без расширения прежнего правила категорий |
| Приступы тревоги/панические проявления | V03, V07–V10; см. исследование/пробел панической ветви в external-check.md | Записать приступы и вопросы; ГТР не равен паническому расстройству. До точной отдельной основы и клинической проверки — никакой автоматической диагностики, категории или медицинского триггера |
| Телесные жалобы | V07–V10; S301/S457, дифференциальная оценка | Соматические причины не исключены анкетой; врач выбирает оценку. Ярлык психосоматики не выводится |
| Потенциально срочная соматическая ситуация | V10/FV04 | Сценарий проверки специалистом, а не утверждённая формула срочности; новый автоматический триггер заблокирован |
| Критические психические сведения | V09/FV05 | Сведения заметны; автоматические признаки/реакция требуют точного источника, утверждения и испытания S17D, без диагноза/госпитализации из одного ответа |
| Неполнота/конфликт/возраст | V01 и любые неизвестные | Черновик и недостающие сведения; никакой «низкой» категории по отсутствию данных |
| Повторное обращение | V12/FV07 | Наблюдение и новые версии; F41.1/A02-v2 действуют только в прежних точных синтетических границах |

Категория «обязательно/желательно», срочность, основание и недостающие сведения — четыре отдельных поля. Из предложенного сбора данных автоматически не следует ни одна категория. Старое правило F41.1 сохраняется со своими условиями, без переноса на эти ветви. Новые клинические правила не исполняются до источниковой и фактической независимой проверки конкретной версии в S17D; отсутствие проверяющего оставляет блокер, не заменяется пересказом преподавателя.

## Проект безопасности и сводки

P06 требует отдельного пакета каждого будущего правила: точный источник/версия/страница, применимость, входы/состояния/время, формула срабатывания, неизвестность/конфликт, текст реакции, адресат и резерв, клиническое заключение о версии, положительные/отрицательные проверки. Сейчас такого утверждённого пакета для V09/V10 нет. Одного поля «мысли» или суммы недостаточно для произвольной срочности/госпитализации. Нельзя показывать «нет риска» из-за отсутствия старого A02-v2.

После утверждения нового правила проверить весь путь: атомарный приём→событие→очередь→заметный сигнал→квитанция доставки→просмотр→принятие к работе→записанная реакция. Повтор/ошибка/восстановление не создают двойного действия. Нет связи — событие без случайного врача; закрытый кабинет/сбой не равны доставке. Локальный резерв S10, отсутствие 24×7 и возможная потеря данных после последней копии S15 сохраняются. Подтверждение лечения/направления/изменения плана остаётся отдельным серверным действием врача.

Сводка будущего S17C содержит отдельно: слова пациента, документированные врачебные факты, результаты точного инструмента, пробелы/конфликты, проект решения и уже подтверждённый план. Полное заполнение формы не устанавливает диагноз. Критические сведения и неполнота не прячутся раскрытием технических источников.
