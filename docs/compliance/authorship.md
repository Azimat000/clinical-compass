## Учёт реального вклада

Для каждого результата перед передачей S17/S22 записать: безопасный код участника, сделанную часть, дату, коммит/артефакт, источник заимствований, проверяющего и статус прав. Пока индивидуальный вклад не распределён, авторство конкретных лиц не установлено. ИИ-помощь раскрывать в форме, которую подтвердит организатор (Q08); использование Codex при разработке уже заявлено пользователем и не скрывается.
