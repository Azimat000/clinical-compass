## Ввод, повтор и неполнота

- Пустая/неверная/будущая дата, неверный тип/слишком длинный текст/служебный символ, противоречивый статус и текст → ошибка без частичных записей (test_records/security/extraction).
- Unknown/denied/conflicting различаются; расхождение возраста/даты рождения не даёт взрослый допуск; ровно18 для лекарства не превращается в19; источники/форма/снимок устаревают → повторная проверка, не автоматическое разрешение (test_ages/assessments/therapy/clinical_rules/workflow).
- Каждый пропуск анкеты проверен; итог не считается с нулём вместо пропуска; пациент видит квитанцию, не баллы/врачебную интерпретацию (test_assessments).
- Один ключ+то же содержимое → одна запись; другой текст с тем же ключом →409. Ошибка посреди транзакции откатывает отчёт/наблюдения/событие, исходная форма после устранения сбоя сохраняется один раз (test_security mid_write, test_records/notifications/communication/decisions).
- Доставка, просмотр, принятие и реакция врача остаются разными состояниями. Ошибка worker → отложенный повтор/dead; незнакомая тема не выдаётся за доставку. Критическое событие не исчезает при недоступном враче (test_critical_delivery/clinical_workflow/foundation).
- Истёкшая/отозванная сессия/закончившаяся связь/отключённый пользователь отнимают доступ. Смена снимка не даёт подтвердить старое решение; проверены все пять видов действий.
