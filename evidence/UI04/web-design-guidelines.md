# UI04 — проверка по Web Interface Guidelines

22.10.2026. Закреплённая копия правил: `.claude/skills/web-design-guidelines/guidelines.pinned.md` (свежая версия по сети не запрашивалась). Файлы: doctor_base.html, dashboard.html, doctor_patient.html, follow_up.html, раздел «Кабинет врача (UI04)» в app.css.

| Область | Результат |
|---|---|
| Доступность | Ссылка «К содержанию» ведёт на `#main`; одна `<h1>`, разделы `<h2>`, подразделы `<h3>`; таблицы с `<caption>` (скрытым) и `<th scope="col">`; поиск и фильтры с подписями; флаги словом и полной причиной для скринридера; значок самочувствия декоративный там, где рядом слово. `Меню` — `<details>`, работает без скриптов |
| Фокус | Глобальный `:focus-visible`, у сегментов `outline-offset: -3px`, на угольной полосе кольцо белое; `outline: none` нет |
| Формы | У полей `name` и подписи; служебные поля `autocomplete="off"`, возраст `inputmode="numeric"`, плейсхолдер заканчивается «…»; ошибки у поля и сводкой `role="alert"` (`#assessment-error`, `#age-error`, `#period-error`), введённые значения сохраняются (тесты); при отправке защита повтора по ключу запроса — серверная |
| Навигация и состояние | Фильтры, период и поиск — параметры адреса (`?show=…&age_status=…`), ссылки открываются в новой вкладке; разрушающее действие «Отозвать приглашение» просит подтверждения (`<details class="revoke">`) |
| Типографика | «…» и кавычки «ёлочки»; `tabular-nums` через `.num`/`time`; `text-wrap: balance` у заголовка; даты и числа PT Mono |
| Содержимое | Длинные тексты переносятся, пустые состояния есть (break-ui.md); `translate="no"` у имён и номеров |
| Касание | `touch-action: manipulation` у кнопок; на ≤1100px кнопки, поля, сегменты и ссылки действий 44 px; на компьютере поля и кнопки 36 px (DESIGN.md) |
| Движение | Новых анимаций нет (срез UI07); `prefers-reduced-motion` из основы |
| Темы | `color-scheme: light`, `theme-color` совпадает с угольной полосой; у `select` заданы цвет и фон |
| Производительность | Таблица списка до 100 строк, отрисовка 0,05 с; шрифты локальные с `preload` и `font-display: swap`; внешних ресурсов нет |
| Якоря | `scroll-margin-top` у разделов карточки |

Замечания и решения:
- Страница не использует `Intl` и язык браузера: даты и «МСК» форматирует сервер (так же, как кабинет пациента).
- Цели касания таблицы на компьютере (ссылка «к записи», «Сводка к приёму») 24–32 px: достаточно для WCAG 2.2 AA 2.5.8 (24 px), 44 px только на планшете и телефоне.
- Список более 50 строк не виртуализирован: предел 100 строк задан сервером.
- Не проверялось: чтение скринридером, Firefox, WebKit.
