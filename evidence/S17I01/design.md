# Решение по экрану

S17I01, 21.10.2026. Самопроверка агента на синтетике.

Композиция: карточка пациента → выбор периода → неполнота → наблюдения/НЯ → анкеты → подтверждённые решения → выполнение. Одна колонка, ссылки на исходники у каждой записи; навигация по разделам. Существующие графики остаются в карточке. Форма GET сохраняет период в URL. Кнопка «Показать сводку» только читает данные. Состояния: заполнено, пустой период, неполная анкета, нет отметки, противоречие, ошибка периода, отказ доступа.

Использованы существующие шаблоны и токены HAC: фон #f3f6f5, поверхность #fff, текст #18352f, акцент #17634d, предупреждение #704508 на #fff4de. Системный шрифт с кириллицей, существующая шкала заголовков и отступов, без новых пакетов/шрифтов/CDN. На узком экране поля периода идут друг под другом; длинные записи переносятся.

Референсы — работающие patient.html, communication.html и first_visit.html. Новых внешних фактов и референсов не потребовалось. Принцип: автор/дата/исходник важнее декоративного показателя; неизвестность не превращается в ноль. Сводка показывает сведения, известные сейчас, а не исторический снимок на выбранную дату. Периоды DASS выводятся ровно из сохранённой версии формы, календарные границы не выдумываются. Поля первого/повторного приёма сохраняют собственные даты, источники и основания.

Критика перед проверкой: длинные идентификаторы и дата с часовым поясом могут расширить страницу на 320px; проверить реальным браузером. Отказ/пустота не должны убирать форму периода. Цвет не заменяет текст состояния. Базовые снимки карточки получаются из её точной версии в исходном Git-коммите через отдельный загрузчик шаблона на временной БД.
