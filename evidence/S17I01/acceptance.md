# S17I01: сводка повторного приёма

STATUS: ACCEPTED
DATE: 21.10.2026 Europe/Moscow

Реализована только фактическая сводка для ведущего врача: `/patients/<patient_id>/follow-up`, переход из карточки. Отбор по периоду включительно; наблюдения/анкеты по дате наблюдения, решения по вступлению в силу, пункты по назначенному сроку с учётом московского дня. Источники, авторы, время получения и подтверждения сохранены. Сохранённые первые/повторные приёмы показаны по последней версии с датами/основаниями каждого поля; исходные импортированные визиты не дублируют новые записи.

Данные читаются в одной транзакции чтения. Последнее подтверждённое решение перед периодом переносится в сводку вместе с изменениями внутри периода. Проекты/отказы не становятся планом. Все отметки выполнения, включая исправления после периода, показаны с авторами; заменённый пункт исключается по существующему правилу. Сводка прямо объясняет, что показывает сведения, известные сейчас, а не состояние информации на прошлую дату. Точной даты фактического выполнения в прежней модели нет; дата срока не подставляется вместо неё. Показаны пункты текущей связи, полнота расписания не предполагается.

Период анкеты взят из сохранённой версии формы: «На прошлой неделе». Календарные границы не выдумываются. Неполная анкета не получает сумм. Возраст русской валидационной выборки остаётся неизвестным, политика HAC 18–120 не выдана за возраст исследования. Текст/ключ/источники DASS не изменены. Клинические правила/FU, дозы, диагнозы, причинность НЯ, срочность и автоматические рекомендации не добавлялись. Прежнее подтверждение врача обязательно.
