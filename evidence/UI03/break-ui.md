# break-ui: кабинет пациента (UI03)

22.10.2026. Данные — учебные пациенты WD01–WD05 (var/ui03-review-20261022.sqlite3, не в Git) и подстановка худших значений через те же поля формы. Проверено во встроенном браузере на 375 px (мобильный режим) и 1440 px, поиском выхода за правый край окна и глазами по снимкам.

## Карта значений

| Поле | Источник | Предел | Необязательное |
|---|---|---|---|
| Имя пользователя в полосе | users.display_name | не ограничено | нет |
| Код приглашения | поле ввода, `maxlength=128` | 128 символов | нет |
| «Что важно рассказать врачу», описания сведений | textarea, серверный предел записи | из records.py | да |
| Записи дневника: резюме, описание сведений | пациент и врач | то же | да |
| Предупреждения о расхождениях | records.warnings | список | да |
| Срок анкеты | assessments.with_deadline | дата | нет |
| 42 утверждения DASS-42 | определение шкалы, без изменений | 42 | нет |

## Что проверено и результат

| Случай | Результат |
|---|---|
| Длинный текст без пробелов в резюме и описаниях, 375 px | переносится, горизонтальной прокрутки нет (`scrollWidth ≤ innerWidth`) |
| Пустые состояния: нет отметок, нет записей, нет анкет, нет отправленных, нет связи с врачом | у каждого есть фраза и, где уместно, действие |
| Много записей и расхождений | расхождения свёрнуты в `<details>` со счётчиком, записи — список со свёрнутыми подробностями |
| Несколько анкет сразу | на «Сегодня» кнопка у первой и строка «Есть ещё анкеты от врача: N» |
| Анкета с неизвестным возрастом | анкеты нет, предложения не создаётся (серверное правило сохранено) |
| Медленная сеть при отправке самоотчёта | сообщение об ожидании; повторный клик во время отправки даёт один запрос |
| Обрыв сети при отправке самоотчёта | ошибка с кнопкой «Повторить отправку»; повтор тем же ключом создаёт одну запись, автоповтора нет |
| Ошибка сервера 400 | заметка вверху, введённые ответы остаются в форме |
| Анкета: отправка с пропусками | первое нажатие предупреждает и меняет подпись кнопки, второе отправляет |
| Анкета: двойной клик по отправке | после первой отправки форма помечена (`aria-busy`, «Отправляем…»), второй клик отменяется |
| Возврат кнопкой «назад» после отправки | `pageshow` снимает состояние «Отправляем…» |
| Счётчик ответов | не зачитывается скринридером на каждый ответ (убран `role="status"`); отдельный скрытый статус объявляет только отправку |
| «DASS-42» в подписях | неразрывный дефис, не переносится |
| Срок «00:00» следующих суток | показывается «ДД.ММ.ГГГГ 24:00 МСК» (дата сегодняшних суток) |
| Цели касания | кнопки и ссылки доступа не ниже 44 px; поля ввода и списки 36 px (размер из UI02, DESIGN.md) |

## Исправлено по итогам проверки

Восемь замечаний независимой проверки и три мелкие правки — см. memory/sessions/UI03.md, раздел «Независимая проверка». Исправлено: тексты без обещания ответа врача; вкладки «Сообщения» нет до UI06; кольцо фокуса вкладок; цели касания; подтверждение удаления черновика без JS; срок «24:00»; счётчик анкеты и состояние отправки; строка о других анкетах.

## Не проверялось

Скринридер, Firefox и WebKit, физические телефоны, масштаб 200 %. Потеря ответов анкеты при обрыве сети принята: карточка черновика для анкеты не требует, а скрипт не использует localStorage.
