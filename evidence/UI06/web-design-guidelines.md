# UI06 — проверка по Web Interface Guidelines

22.10.2026. Закреплённая копия правил: `.claude/skills/web-design-guidelines/guidelines.pinned.md` (свежая версия по сети не запрашивалась). Файлы: communication.html, notifications.html, critical.html, receipt.js, doctor_base.html (меню и полоса), patient_base.html (вкладка), раздел UI06 в app.css.

| Область | Результат |
|---|---|
| Доступность | Одна `<h1>`, разделы `<h2>`, форма и события `<h3>`; пропусков уровней нет. У строки разделов пациента и вкладок `aria-current="page"`. Ошибка — `role="alert"` сверху экрана со ссылкой «К форме» / «К полю реакции»; полоса критического события `role="alert"`; статус скрипта получения `role="status"`. Счётчики меню дополнены скрытым словом («ждут подтверждения»). Дублей id на экране нет (тест `test_both_roles_…`) |
| Фокус | Глобальный `:focus-visible`, `outline: none` нет. Ссылки `#message-…`, `#task-…`, `#event-…` и `#reaction-…` приводят к цели; `scroll-margin-top` у карточек; записи в закрытых `<details>` раскрывает `doctor_forms.js` при переходе по якорю |
| Формы | Поля с `name` и подписью; пункт плана и сообщение — `<textarea>` с `maxlength` как у сервера (4000, 500, 1000, 2000); время — `type="datetime-local"`; флажок подтверждения — `<label class="option">` (вся строка — цель). Кнопка остаётся доступной до начала отправки, затем подпись с «…» и `aria-busy` (`form[data-busy]`) |
| Ошибки | Сверху экрана, словами, что не сохранено и что осталось в форме; введённое сохранено; у формы новый ключ повтора |
| Навигация и состояние | Якоря после действий: `#message-ID`, `#task-ID`, `#notification-ID`, `#event-ID`; «Написать» ведёт к `#compose`. Деструктивных действий нет: все отметки журнальные и неотменяемые, поэтому каждая названа словами («Отметить: просмотрено») и стоит отдельной кнопкой |
| Типографика | «…» и «ёлочки»; время и число — PT Mono через `.num`; даты в `<time datetime>`; `text-wrap: pretty` у текстов; имена и номера с `translate="no"` |
| Содержимое | Тексты пользователя в `.keep` (перенос и сохранение абзацев); пустые состояния названы словами; длинный список сокращён (8 сообщений, 30 уведомлений, закрытые в `<details>`); break-ui.md |
| Касание | На ≤1100 px кнопки и поля врача 44 px (общее правило `.main`); у пациента кнопки и ссылки действий не ниже 44 px (правило `.p-main`); кнопки отметок на телефоне на всю ширину |
| Движение | Новых анимаций нет (срез UI07); `prefers-reduced-motion` учтён общим правилом |
| Производительность | 126 сообщений — 142 КБ, 0,05 с; 27 уведомлений — 46 КБ; скрипт один, `defer`; внешних ресурсов нет |
| Безопасность разметки | Нет `style=`, `<script>` без `src`, `on…=`; данные только через автоэкранирование (тесты на `<script>` в тексте сообщения и в отметке) |
| Скрипт | Без `receipt.js` экран критических событий полностью работает кнопками; `receipt.js` не рисует время получения сам, а перезагружает страницу после ответа сервера 204 |

Замечания:
- Время пункта плана врач вводит по Москве; сервер получает его со смещением +03:00. Часового пояса, отличного от московского, поле не предлагает (сервис ведёт все сроки по МСК).
- Фокус на первое поле с ошибкой автоматически не переносится: вместо этого сверху ссылка к форме (как в UI05).
- Не проверялось: чтение скринридером, Firefox, WebKit.
