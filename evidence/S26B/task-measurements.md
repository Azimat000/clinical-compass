# Измерения задач врача, S26B

Дата: 21.10.2026 (Europe/Moscow). Среда: Chromium 151.0.7922.34, macOS, окно 1440×900, синтетическая база (evidence/S26B/prepare.py), один вымышленный врач doc-a. Это сценарий, выполненный скриптом основного агента, а не участие врача и не измерение времени живого человека. Действие = один щелчок по ссылке или кнопке либо заполнение одного поля. Вход в систему не считается. «До» — состояние коммита a81d278 (после S26A), «после» — рабочее дерево S26B; обе версии на одной и той же базе. Скрипт: evidence/S26B/tasks.cjs, результаты: tasks-before.json, tasks-after.json.
