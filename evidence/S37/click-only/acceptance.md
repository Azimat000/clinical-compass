# S37 — Исправление автоматического открытия

STATUS: ACCEPTED
DATE: 24.10.2026 Europe/Moscow
CORRECTIVE_REF: refs/tags/fix/S37-invitation-click-only

Причина: обработчик openBookmark открывал окно по #invitations при загрузке и смене якоря. Удалён. Единственный вызов открытия теперь в обработчике явного нажатия. При pageshow с persisted=true ранее открытое окно закрывается, чтобы возврат из кэша тоже ждал нового нажатия.

| Требование | Доказательство | Результат |
|---|---|---|
| Закрыто при загрузке и обновлении | browser.json: Chromium/Firefox/WebKit — обычный вход, адрес с #invitations, обновление закрытого/открытого окна, смена якоря | PASS |
| Возврат не открывает окно | Реальный переход к карточке и Back; отдельно событие pageshow с persisted=true | PASS |
| Открывать только нажатием | Кнопки на 1440 и 375px, Escape после открытия, без ошибок JS | PASS |
| Работающий сервис обновлён | HTTP-содержимое invitations.js побайтово совпало с файлом; SHA256 в browser.json | PASS |

Проверки основной агент выполнил непосредственно на отдельной var/S37-ui-check.sqlite3; рабочая база не изменялась. node --check и git diff --check PASS. Полный make check повторно не запускался: исправлены только события браузера, проверенные отдельным регрессионным сценарием. Предыдущие 520+70 тестов относятся к исходной приёмке S37. Визуальное оформление, серверные POST, права и CSRF не менялись. Новых расходов/источников/зависимостей нет. UI08 остаётся отдельной.
