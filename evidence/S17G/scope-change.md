# Изменение объёма по прямому поручению пользователя

20.10.2026 в ходе S17G пользователь: «Не надо мне пока презентацию и орг моменты делать, делай только сервис. Запомни это и на остальные сессии».

Новый приоритет сохранён в AGENTS.md, START_HERE.md, memory/DECISIONS.md и STATE.work_policy. Презентации/организационная подготовка не являются результатами принимаемого S17G. Начатые локальные материалы убраны в игнорируемый tmp/s17g-deferred/, не публикуются, не включаются в коммит и не предлагаются пользователю. Исходная карточка/manifest доступны в Git на baseline 608dc0740d2451368eeef98d42e868aa3df1e1d5; их история не переписывается.

Вместо презентационной части текущий S17G проверяет сервис: две сессии врача/пациента, домашняя анкета, дневник/выполнение/сообщения/подтверждённый план и явное отображение фактического срока отправки по Москве. Новые клинические рекомендации и обмен между врачами не входят в срез. Официальные 83 требования/160 подпунктов сохраняются с прежними статусами; отложенные задачи не объявляются выполненными.

Изменения файлов выполняет только основной агент. Исследователь external_s17g был read-only и завершился до нового поручения; других агентов нет. Старая обязательная проверка почты/публичных условий уже выполнена до изменения приоритета и не повторяется. Будущие сессии не запускают такие организационные задачи автоматически; необходимые основания/права/безопасность сервиса проверяются по затронутой функции.
