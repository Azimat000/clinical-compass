# Предложение по порядку работ — пока не применено

В B03B найден конфликт: его приёмка требует полных лекарственных досье, а срез их подготовки C ждёт принятия B, который ждёт B03B. Одной проверки графа зависимостей недостаточно: обратное требование находится в критериях и frozen-матрице.

Предлагается выделить девять подготовительных срезов C01–C09 — по одному для каждого препарата уже замороженного перечня. Каждый собирает все десять разделов точного досье и проверяет официальную информацию безопасности. Они могут начаться после принятого B03A. B03B затем ждёт все девять досье; итоговый C по-прежнему ждёт B, все досье и полный COVERAGE-1.

Все исходные работы, результаты и критерии B/B03/B03B/C сохраняются дословно. Обязательные 58 вопросов, 224 аспекта, 9 досье и 90 разделов не меняются. Неизвестный возраст русской DASS не объявляется установленным. Подготовка досье не включает запуск поиска, назначения или активацию клинических правил.

Точные новые карточки в формате manifest и изменения только зависимостей — plan-amendment-proposal.json. Предложенный граф проверен: цикла нет; исходные задачи/результаты/критерии сохранены. Рабочие manifest, frozen-матрица и зависимости не изменены.

Изменение требует явного решения пользователя, потому что действующие карточки B03/B03B отдельно запрещают обход зависимости C планом. До этого подготовительные срезы не созданы и C не начат. После согласования первым будет одно досье — эсциталопрам; общий барьер готовности остаётся прежним.
