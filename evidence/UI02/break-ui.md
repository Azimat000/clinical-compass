# break-ui: вход, итог действия, общие компоненты (UI02)

22.10.2026. Худшие данные подаются через ту же границу, что и обычные: контекст шаблона. Служебный переключатель «Обычные данные / Худший случай» и страницы предпросмотра живут только при `COMPASS_UI_GALLERY=1`: `/ui/components?data=worst`, `/ui/components/login-error?data=worst`, `/ui/components/login-locked?data=worst`, `/ui/components/result?data=worst`. Данные — apps/compass/ui_fixtures.py. Проверено во встроенном браузере на 320, 375 и 1440 px; поиском элементов, выходящих за правый край окна (скрипт в браузере), и глазами по снимкам.

## Что сломалось и исправлено

|---|---|---|---|---|---|
| 1 | Broken | сетка любого раздела | ширина 320 px | `minmax(280px, 1fr)` шире доступного места: колонки, поля и подсказки уходили за правый край | `minmax(min(280px, 100%), 1fr)`, apps/compass/static/app.css (раздел «Каталог компонентов»); уменьшены отступы листа каталога на телефоне |

| 3 | Ugly | шапка листа | «Клинический компас» + длинная пометка | марка переносилась на две строки | марка без переноса, шапка листа переносит пометку на вторую строку (`flex-wrap`) |
| 4 | Fragile | любой длинный текст без пробелов | код, адрес, логин 100 символов | мог выйти за край | `overflow-wrap: break-word` на body (правка из проверки web-design-guidelines) |

## Решения для следующих срезов

- «DASS-42» в подписи на всю ширину переносится по дефису («DASS-» / «42»). В экранах UI03 писать неразрывный дефис (U+2011) или оборачивать название шкалы в элемент без переноса.
- Длинный логин (100 символов) в поле не переносится, а прокручивается внутри поля, как у любого `<input>`. Оставлено: так ведут себя поля ввода везде.
- Сообщения `str(error)` с сервера не ограничены по длине. Страница итога их переносит; если в UI03+ появятся сообщения длиннее пяти строк на телефоне, их стоит сократить на сервере, а не обрезать в интерфейсе.

## Что выдержало

- Длинное сообщение о сбое (5 предложений) с кодом инцидента на 320 px: переносится в рамке, код отдельно моноширинным, кнопка «Перейти ко входу» на всю ширину.
- Длинный логин после ошибки входа: остаётся в поле, пароль не возвращается в разметку (тест `test_failed_login_names_problem_keeps_login_and_never_echoes_password`).
- Блокировка входа: отдельная форма уведомления (двойная линия), не путается с неверным паролем.
- Пять отметок «не указано» подряд: пунктирные метки различимы без цвета; подпись для скринридера перечисляет все пять.
- Длинные флаги: код словом укладывается, полная причина — скрытым текстом и подсказкой.
- Маркер причины в две строки повторяет подложку на каждой строке (`box-decoration-break: clone`).
- Горизонтальной прокрутки страницы нет ни на одной проверенной ширине (`scrollWidth = innerWidth` на 320).

Не проверялось: масштаб браузера 200 % отдельно (ширина 320 px по WCAG 1.4.10 покрывает тот же перенос), тёмная тема (не решалась в UI01), письмо справа налево (не нужно для русского интерфейса).
