# Решение перед реализацией

Исходные экраны: before-doctor.png / before-patient.png, IAB, синтетические D01/D02. У врача поиск ниже обучения/приглашения; пациенту приходится читать всё подряд. Базовые задачи работают, но обзор и ввод не разделены.

Палитра: фон #f3f6f5, поверхность #ffffff, текст #18352f, вторичный #52665f, акцент #17634d, граница #c6d4ce. Предупреждение #704508 / #fff4de, критический сигнал #861f23 / #fff1ef. Системная кириллица, основной 16px/1.55; h1 30–36, h2 23, подписи 14–16. Без сторонних шрифтов, изображений, библиотек, градиентов, декоративных графиков.

Композиция: общий компактный верх с ролью и выходом; слева на широком экране постоянное меню врача, в мобильном — переносимые строки меню. Рабочая область с заголовком, контекстом и задачей. Список пациентов — строки, поиск первый, приглашение в раскрытии. Карточка — обзор и переключаемые по обычным ссылкам разделы: запись, динамика, анкеты, данные врача. Без JS видны все разделы. Клинический сигнал остаётся вне переключения.

Главное действие пациента — добавить самоотчёт; врача — открыть случай/добавить визит. Тексты клинических шкал/порогов/источников не менять. Обязательно: слово и ⚠/сплошная рамка; желательно: слово и ◇/штриховая рамка. Неизвестное отдельно от отрицания, проект отдельно от подтверждения.

Проверка плана: убраны прежние рекламный блок будущих возможностей, верхнерегистровые подписи и одинаковые карточки. Характер инструмента создают читаемый список, контекст пациента и раздельные задачи. Ошибки должны открывать нужный раздел и сохранять значения. Ссылки на старые якоря должны продолжать работать; навигация назад возвращает раздел. Клавиатура, 320/768/1024/1440, длинный текст, масштаб/ошибки/пустая выборка проверяются после реализации. Это самопроверка агента, не апробация S16.
