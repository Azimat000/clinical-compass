# UI05 — break-ui: худшие данные в решениях, приёме и документах

22.10.2026. Отдельная учебная база var/ui05-worst-20261022.sqlite3 (копия базы худших данных UI04, `.gitignore` скрывает var/; вымышленные пациенты). В неё добавлены: проекты и подтверждённое решение с «словами» по 1000+ знаков без пробелов и разметкой, оценка терапии по 8 областям с максимальными заметками, приём со всеми полями на пределе длины, документ с 547 кандидатами. Ширины 1440, 1024, 375; девять страниц на каждой ширине проверены по ширине содержимого скриптом в браузере.
