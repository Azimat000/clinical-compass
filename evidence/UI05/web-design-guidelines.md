# UI05 — проверка по Web Interface Guidelines

22.10.2026. Закреплённая копия правил: `.claude/skills/web-design-guidelines/guidelines.pinned.md` (свежая версия по сети не запрашивалась). Файлы: decisions.html, first_visit.html, imports.html, макрос `patient_nav` в components.html, doctor_base.html, раздел «UI05» в app.css, doctor_forms.js.

| Область | Результат |
|---|---|
| Доступность | Одна `<h1>`, разделы `<h2>`, записи `<h3>`; подзаголовки внутри записей — не заголовки (`.subhead`), чтобы не было пропуска уровней; группы полей — `<fieldset><legend>` (область оценки терапии, раздел приёма, вид направления); таблицы с скрытым `<caption>` и `<th scope="col">`; строка разделов пациента — `<nav aria-label>` с `aria-current="page"` |
| Фокус | Глобальный `:focus-visible`; `outline: none` нет; прилипшая панель сохранения не закрывает поле при переходе по Tab (`scroll-padding-bottom`) |
| Формы | У каждого поля `name`, подпись и, где нужно, подсказка; `autocomplete="off"` у служебных полей; возраст `inputmode="numeric"`; `required` только у всегда обязательных полей (условные проверяет сервер, иначе скрытые поля блокировали бы отправку); значения сохраняются при ошибке (тесты); кнопка не отключается до отправки, после — «…» и `aria-busy`; повтор отправки отменяется |
| Ошибки | Сводка вверху страницы с `role="alert"` и якорем (`#form-error`, `#visit-error`, `#import-error`), ссылка «К форме»; текст говорит, что не сохранено |
| Навигация и состояние | Адреса переносят состояние: `?revise=` (новая версия на основе проекта), `?review=` (форма сверки кандидата), `#decision-…`, `#import-…`; перенос по якорю раскрывает `<details>` |
| Подтверждение | Разрушающих действий нет; «Отклонить проект» и «Подтвердить решение» — отдельные кнопки с обязательным обоснованием и отметкой просмотра; результат показывается только по записи сервера |
| Типографика | «…» и «ёлочки»; `tabular-nums` через `.num`/`time`; `text-wrap: balance` у заголовка; даты и номера PT Mono; `translate="no"` у имён и номеров |
| Содержимое | Длинные тексты переносятся (`overflow-wrap: anywhere`), пустые состояния названы словами (break-ui.md) |
| Касание | На ≤1100 px кнопки, поля и ссылки действий 44 px; на компьютере 36 px (DESIGN.md); строка разделов пациента на телефоне прокручивается и сама показывает текущий пункт |
| Движение | Новых анимаций нет (срез UI07) |
| Производительность | Самая тяжёлая страница (документ из 547 кандидатов) 410 КБ, 0,08 с; шрифты локальные; внешних ресурсов нет |
| Безопасность разметки | Нет `style=`, `<script>` без `src`, `on…=`; данные пользователя только через автоэкранирование |

Замечания и решения:
- Подтверждение просмотра — флажок «Сведения, на которых основан проект, просмотрены»; сервер требует его отдельно (`reviewed=yes`).
- Условные группы полей (направление, терапия) без скрипта показаны обе и подписаны «Нужно только для…»; со скриптом показывается нужная.
- Не проверялось: чтение скринридером, Firefox, WebKit.
