# S38 — Дневник по назначениям врача

Прямое поручение 25.10.2026 с уточнением: сохранить жалобы отдельным блоком с прежними состояниями/описанием, убрать остальные поля «Дополнительные сведения для врача» и «Принимали Авиандр?». Показывать пациенту назначенные через сайт препараты; для каждого несколько вариантов «Есть эффект / Нет эффекта / Нежелательные явления» с отдельными описаниями. Ответы видит врач; при нежелательных явлениях пациент выделен как требующий внимания.

План: использовать подтверждённый полный состав препаратов S33, сохранять связь с неизменяемой версией назначения и название с сервера. Сохранить черновик и безопасный повтор отправки. Отобразить ответы в дневнике, карточке и сводке; включить их в фактические причины списка S31, без диагнозов и автоматического изменения терапии. Проверить роли, CSRF, подмену назначения, ошибку/повтор/черновик/перезапуск, телефон и компьютер с JS и без него. Сохранить рабочую базу; память, матрица, коммит и тег. Общая UI08 отдельно.

Отметка без выбранного варианта — отсутствие сведений. Несколько вариантов допустимы, каждый требует своего текста. Новое молчание не отменяет прежнее сообщение о нежелательном явлении. После замены состава врачом старая неотправленная форма отклоняется с сохранением черновика; прежние отправленные записи неизменны.
