# UI07 — Движение и тонкая доводка

Навыки: `emil-design-eng` (принципы движения и микровзаимодействий), `review-animations` (проверка анимаций), `impeccable` (полировка).

1. Переходы, нажатия, появление ошибок и успеха имеют короткую осмысленную анимацию только там, где она помогает понять результат; ничего не задерживает работу.
2. `prefers-reduced-motion` уважается везде; анимации только через transform/opacity, без рывков на слабом телефоне.
3. review-animations пройден по всем экранам, найденное исправлено или записано с причиной.
4. Функции и тесты UI02–UI06 не сломаны.
