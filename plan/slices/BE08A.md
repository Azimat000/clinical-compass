# BE08A — Проверяемые смысловые кандидаты из четырёх источников

Статус: PLANNED. Дочерний срез BE08, 26.10.2026.
Зависимости: BE05, BE07

## Работа

- Проверка каждого поля/ссылки/цитаты и полных дат в неизменном снимке.
- Изолированный модельный поиск кандидатов; независимое сохранение правил BE07; честная частичность при сбое.

## Условия приёмки

- BE08A-A01: Все четыре источника, версии/пустоты/даты/цитаты проверены; выдуманная ссылка/цитата атомарно отклоняется.
- BE08A-A02: Модельные кандидаты отдельно от правил и заключений врача; сбой/пустой ответ не означает отсутствия риска, положительное правило сохраняется.
- BE08A-A03: Реальный синтетический вызов и ошибка; замеры только кандидатов на фиксированном наборе, без заявления полной приёмки BE08.

Общие границы/проверки/память/синтетика/коммит: plan/slices/BE08.md и plan/backend/SESSION.md. Одна сессия — только этот срез. BE08A не завершает исходный BE08.
