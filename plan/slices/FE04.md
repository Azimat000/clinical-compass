# FE04 — Общие элементы и навигация интерфейса

Статус: PLANNED. Поручение: 27.10.2026. Одна сессия — один срез.
Зависимости: FE03. Общий план: `plan/frontend/README.md`.

## Работа

1. Внедрить выбранную композицию, шрифты/цвета/отступы, меню врача и пациента, заголовок пациента и общие элементы форм без смены Flask/Jinja/CSS/обычного JS.
2. Реализовать общий показ состояния анализа, обновления, ошибки и доступности; защиту несохранённого ввода и предсказуемый фокус. Для нужных форм оставить рабочий путь без JavaScript.
3. Подключить безопасное обновление данных: ограниченный опрос существующего запроса, остановка на скрытой вкладке/при выходе, отсутствие дублей и хранения клинического текста в браузерном storage.

## Условия приёмки

- FE04-A01: Все существующие разделы доступны обеим ролям в согласованной оболочке; нет сломанных старых адресов/ссылок.
- FE04-A02: Общие состояния проверены на 375/768/1440 px с клавиатурой, увеличением 200%, длинным текстом, без JS и с reduced-motion; ожидание не блокирует чтение.
- FE04-A03: CSP/локальные шрифты/отсутствие CDN сохранены; повтор/ошибка/истечение сессии не теряют ввод и не показывают ложное сохранение.

## Проверки и передача

Прочитать START_HERE/AGENTS, STATE, память решений/блокеров/источников/бюджета, последний принятый отчёт, этот файл и `plan/frontend/SESSION.md`. Проверить источниковые сроки и лимит перед модельными запросами.

```sh
python3 tools/design_skills.py check
python3 tools/validate_plan.py
python3 tools/session.py status
git diff --check
python3 tools/session.py start FE04
```

`start` выполняется один раз перед работой, остальные команды — до/после. Конкретные существующие целевые тесты выбрать по изменяемым модулям, записать команды и результаты в отчёте; браузерные действия и доказательства каждого Axx обязательны для изменённых экранов. Общий `make check` не запускать автоматически: прежнее поручение об отсрочке сохраняется.
