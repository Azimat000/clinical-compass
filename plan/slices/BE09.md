# BE09 — Доставка сигналов только врачу

Статус: ACCEPTED (технически). Поручение: 26.10.2026.
Зависимости: BE07, BE08.
Исходные требования (план покрытия, не выполнение): F06, M01, M02, M05, M10, T01, T07, T13.

## Работа

1. Интегрировать сигналы с существующим серверным журналом и механизмом доставки. Реализовать API врачебной очереди, просмотр/решение и историю, не возвращая удалённые экраны уведомлений.
2. Различать создано, поставлено на доставку, доставлено в врачебный канал, просмотрено и обработано. Подтверждение транспорта не является клиническим решением.
3. Учесть ведущую связь, смену/отключение врача, отсутствие адресата, повтор доставки и исчерпание попыток. Резервный адресат возможен только при явно оформленном праве; иначе виден недоставленный сигнал, без утечки третьему лицу.

## Условия приёмки

- BE09-A01: Сигнал недоступен пациенту и чужому врачу через любые API/выгрузки/события; повтор сохраняет один эпизод и журнал попыток.
- BE09-A02: Проверены сбой доставки, перезапуск, смена адресата и неподтверждённый просмотр. Есть измеренный путь новая запись→сигнал→врачебная квитанция.
- BE09-A03: Транспорт действительно работает в доступном врачебном канале; для внешнего канала нужны отдельные разрешённые настройки. Не заявлена круглосуточная экстренная служба.
