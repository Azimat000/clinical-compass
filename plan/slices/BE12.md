# BE12 — Проект плана обследования и наблюдения

Статус: PLANNED. Поручение: 26.10.2026.
Зависимости: BE03, BE06, BE11, BE08.
Исходные требования (план покрытия, не выполнение): F02, F04, F07, F08, M03, M08, T05.

## Работа

1. Генерировать структурированный план: цели, уточнения/обследования, немедикаментозные меры, наблюдение, оценка ответа и маршрутизация, только где обосновано.
2. Связывать каждый пункт с фактами, выбранным диагнозом/условием, источником и необходимыми уточнениями. При неподтверждённой гипотезе — отдельный условный проект уточнения, без активного лечения.
3. Не создавать лишние обследования ради заполненного ответа; явно различать обязательное/желательное направление только при соответствующем основании.

## Условия приёмки

- BE12-A01: Для поддерживаемого полного случая получается содержательный план; для неполного — конкретные недостающие сведения, а не универсальный шаблон.
- BE12-A02: План согласован с рисками и диагнозом; каждый пункт проверяем. Нет автоматического действия или пациентской публикации.
- BE12-A03: Клинические интервалы/условия пересмотра имеют основание, а не техническую константу; разные сценарии дают осмысленно разные планы.
