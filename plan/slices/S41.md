# S41 — Предложение анкеты без полей возраста

Прямое поручение 25.10.2026: убрать «Возраст, лет» и «Откуда возраст» при предложении анкеты.

Удалить поля Возраст, лет и Откуда возраст из формы предложения анкеты.

Использовать сохранённые возрастные сведения автоматически; сохранить возрастные ограничения, неизвестность и противоречия.

Проверить реальную отправку формы без полей, ошибки, повтор, браузеры и сохранность рабочей базы; обновить память.

Приёмка:

- В форме и после ошибки нет двух удалённых полей и скрытого age_status.
- Форма предлагает анкету без возрастных полей; данные возраста берутся из сохранённых записей на сервере.
- Неизвестность, конфликт и выход за возрастные границы не дают допуска; повтор безопасен и изменившиеся записи делают старое предложение непригодным.
- Исторические данные сохранены, проверки проходят, рабочий сервис обновлён. UI08 отдельно.
