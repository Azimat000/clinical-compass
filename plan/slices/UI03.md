# UI03 — Кабинет пациента: «Сегодня», самоотчёт, анкеты

Навыки: `impeccable`, `design-taste-frontend`; проверка — `break-ui`, `web-design-guidelines`. Телефон в приоритете.

1. patient.html для роли пациента: одно главное действие сразу видно на 375 px; лишних слов нет; пустые, ошибочные и успешные состояния описаны.
2. Самоотчёт сохраняет все гарантии S26D/S27: личный серверный черновик, восстановление, защита повторов и вкладок, ключ повтора, без localStorage/sessionStorage и без автоматического повтора; без JS обычная форма работает.
3. assessment_form.html и assessment_receipt.html: текст и порядок DASS-42 не изменены; пациент не видит сумм и интерпретации; счётчик ответов и проверка пропусков работают.
4. invitation.html и привязка по приглашению работают для пациента.
5. Тесты экранов пациента переписаны под новый HTML и проходят; break-ui (длинные тексты, пустые данные, медленная сеть, повторный клик) без поломок; снимки 375/768/1440.
