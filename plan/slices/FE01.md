# FE01 — Общий UX и дизайн ключевых экранов

Статус: PLANNED. Поручение: 27.10.2026. Одна сессия — один срез.
Зависимости: BE16. Общий план: `plan/frontend/README.md`.

## Работа

1. Сверить реальные экраны, API BE01–BE16 и ограничения; составить карту всех экранов обеих ролей и переходов, включая вход, приглашение, квитанции и ошибки.
2. Спроектировать главную врача с боковой лентой сигналов, карточку с двумя диагнозами и страницу «План и решения». Подготовить связанные локальные прототипы на конкретных историях из scenarios.json.
3. Зафиксировать единое визуальное направление, компоненты, мобильную композицию и состояния. Обновить PRODUCT.md, DESIGN.md, sidecar и брифы через применимый workflow навыков; прежние удалённые композиции не восстанавливать.

## Условия приёмки

- FE01-A01: Карта всех действующих маршрутов обеих ролей связана с будущими срезами; нет потерянных форм, историй, лекарственных отметок или документов.
- FE01-A02: Три ключевых прототипа показывают реальные по структуре сведения, оба диагноза и проект/действующий план; просмотрены на 375/768/1440 px. Это прототипы, не работающие клинические результаты.
- FE01-A03: Память дизайна согласована; назначены состояния ожидания, пустоты, ошибки, неполноты, устаревания, запрета доступа, конфликта и успешного сохранения.

## Проверки и передача

Прочитать START_HERE/AGENTS, STATE, память решений/блокеров/источников/бюджета, последний принятый отчёт, этот файл и `plan/frontend/SESSION.md`. Проверить источниковые сроки и лимит перед модельными запросами.

```sh
python3 tools/design_skills.py check
python3 tools/validate_plan.py
python3 tools/session.py status
git diff --check
python3 tools/session.py start FE01
```

`start` выполняется один раз перед работой, остальные команды — до/после. Конкретные существующие целевые тесты выбрать по изменяемым модулям, записать команды и результаты в отчёте; браузерные действия и доказательства каждого Axx обязательны для изменённых экранов. Общий `make check` не запускать автоматически: прежнее поручение об отсрочке сохраняется.

Результат: `memory/sessions/FE01.md`, `evidence/FE01/acceptance.md`, обновления STATE/матриц/дизайн-памяти. При полной приёмке — коммит `slice(FE01): <проверенный результат>` и тег `slice/FE01`; до тега `validate_plan.py --pending-tag FE01`, после тега обычная проверка. При незавершённости — WIP/blocked без тега принятия. Следующий срез только в следующей сессии.
