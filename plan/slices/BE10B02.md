# BE10B02 — Диагностический API и оценка настоящей модели

Зависимости: BE10B01. Только внутренняя синтетика; clinical_release=blocked.

## Работа

- Реализовать запрос врача на ведущую гипотезу и существенные альтернативы по снимку всех четырёх источников. Клинические критерии и источники — для конкретной поддерживаемой области.
- Для каждой гипотезы возвращать поддерживающие и противоречащие факты, критерии, недостающие различающие сведения и возрастную применимость. Код диагноза только при проверенной системе кодирования.
- Не выводить неподтверждённые проценты вероятности. При недостаточных данных/вне области — объяснимый ответ и вопросы, без произвольного диагноза.
- Подключить внутренний механизм к существующим врачебному API/очереди с актуальностью/правами/отменой и атомарной публикацией.
- Выполнить все исходные BE10-A01–A03 на настоящей модели: независимые метрики альтернатив/опасных пропусков на фиксированном авторском наборе; не считать модульные ответы модельным качеством.

## Условия приёмки

- Реальная модель и проверки дают воспроизводимо проверяемые основания; ссылки соответствуют фактам пациента и действующим критериям.
- Есть тесты похожих состояний, противоречий, недостаточных данных и неподдерживаемого случая. Скрининговый балл сам по себе не устанавливает диагноз.
- Ни генерация, ни повтор, ни чтение результата не создают установленный диагноз или план. Качество альтернатив и опасных пропусков измерено отдельно.
