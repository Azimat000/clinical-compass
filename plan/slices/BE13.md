# BE13 — Проверки лекарственной безопасности

Статус: PLANNED. Поручение: 26.10.2026.
Зависимости: BE02, BE03.
Исходные требования (план покрытия, не выполнение): F03, M07, M08, T03, T05, T10.

## Работа

1. Создать проверяемый лекарственный каталог по конкретным действующим документам ГРЛС: вещество, форма, сила/единицы, показания, ограничения, противопоказания и поддерживаемые взаимодействия.
2. Реализовать серверные проверки возраста, аллергий, текущих препаратов, дублирования, доз/единиц и обязательных индивидуальных сведений для конкретного препарата.
3. Явно хранить полноту покрытия взаимодействий/ограничений; отсутствие записи в каталоге не равно отсутствию противопоказания. Не разбирать свободный текст в активную дозу.

## Условия приёмки

- BE13-A01: Проверены одинаковые вещества под разными названиями, несовместимость, неизвестные обязательные сведения, неверная единица/форма/сила и противопоказанный вариант.
- BE13-A02: Результат по каждой проверке pass/block/unknown с точным основанием; unknown не разрешает непроверенную лекарственную схему.
- BE13-A03: Есть содержательный поддерживаемый каталог и проверки, включая требования M04/M07 при применимости; Элицея/Алевал из демонстрационных историй не объявлены автоматически допущенными.
