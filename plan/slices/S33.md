# S33 — План и календарь препаратов

Прямое поручение пользователя 23.10.2026. Один срез вместо UI08.

1. На главной пациента последний подтверждённый план; проекты скрыты.
2. Врач задаёт название, дробные количества по времени, начало и курс; назначения вступают в силу только после подтверждения.
3. Недельный календарь у обеих ролей; пациент отмечает отдельные приёмы и частичную дозу, исправления сохраняют историю.
4. Пропуск и отсутствие отметки различаются; роли, повторы, устаревшие вкладки, смена плана, данные и проверки защищены.

Только ручная запись врача, без рекомендаций доз, препаратов и действий при пропуске. Старые истории/источники сохранены, новые данные синтетические.
