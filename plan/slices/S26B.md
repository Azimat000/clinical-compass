## Что делаем

1. Переработать главный экран врача «Кому нужно внимание»: журнал пациентов, сигнал без реакции наверху, поиск и фильтры, понятные статусы; сохранить все прежние фильтры и ограничения.
2. Карточка пациента: постоянная шапка (код, возраст/статус сведений, сигналы), короткий набор разделов вместо длинного меню, последовательные задачи Первый приём / Наблюдение / Сводка повторного приёма; решения врача, импорт истории, сверка, критические сигналы и входящие в единой логике.
3. Показывать различия: проект и действующее решение, получение и реакция врача, неизвестно/отрицание/противоречие; не вводить оптимистичное обновление подтверждений.
4. Проверить задачи врача: вход → поиск → карточка → динамика → проект/подтверждение; сигнал → просмотр → принятие → реакция; записать фактические шаги и среду.
