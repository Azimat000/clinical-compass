# UI06B — Пациент: подтверждённый врачом план

Решение пользователя 22.10.2026: пациенту нужен экран подтверждённого врачом плана; делается отдельным срезом после UI06.

Навыки: `impeccable`, `design-taste-frontend`; проверка — `break-ui`, `web-design-guidelines`.

1. Вкладка «План» в кабинете пациента (patient_base.html) и экран на адресе `/patients/<id>/decisions` для роли пациента вместо технического 503. Данные — только пациентская проекция `decisions.history` (подтверждённые решения; без проектов, отклонённых, оценки терапии, разбора направления). Новых данных пациенту не отдавать.
2. Последнее подтверждённое решение сверху, затем история подтверждённых; у каждого вид решения, текст, дата подтверждения, имя врача. Пустое состояние словами: «Врач пока не подтвердил план. Это не означает, что плана не будет».
3. Голос: на «вы», коротко, спокойно; без обещаний реакции врача; не выдавать запись за медицинскую помощь («Демо не оказывает экстренную помощь»).
4. Врачебный экран, серверные правила, API и JSON-клиенты не менять. Тесты, ждавшие 503 для пациента (test_decisions, test_ui05, test_interface_removed), переписать. break-ui на длинных текстах и пустом плане, 375 px.
