# UI06 — Сообщения, уведомления, критические события

Навыки: `impeccable`; проверка — `break-ui`, `web-design-guidelines`.

1. communication.html для обеих ролей: три состояния сообщения различимы словами и видом; отправка и повтор безопасны.
2. notifications.html: список и действия над уведомлениями.
3. critical.html: независимый критический путь заметен и не теряется среди обычных уведомлений; действия подтверждаются сервером.
4. Тесты экранов среза переписаны и проходят; после этого среза ни один экран, кроме экрана плана для пациента (UI06B), не отвечает 503/interface_removed.
