# BE10 — Диагностические гипотезы с обоснованием

Статус: PLANNED. Поручение: 26.10.2026.
Зависимости: BE03, BE05, BE06.
Исходные требования (план покрытия, не выполнение): F02, M08, E01, T02, T03, T05.

## Работа

1. Реализовать запрос врача на ведущую гипотезу и существенные альтернативы по снимку всех четырёх источников. Клинические критерии и источники — для конкретной поддерживаемой области.
2. Для каждой гипотезы возвращать поддерживающие и противоречащие факты, критерии, недостающие различающие сведения и возрастную применимость. Код диагноза только при проверенной системе кодирования.
3. Не выводить неподтверждённые проценты вероятности. При недостаточных данных/вне области — объяснимый ответ и вопросы, без произвольного диагноза.

## Условия приёмки

- BE10-A01: Реальная модель и проверки дают воспроизводимо проверяемые основания; ссылки соответствуют фактам пациента и действующим критериям.
- BE10-A02: Есть тесты похожих состояний, противоречий, недостаточных данных и неподдерживаемого случая. Скрининговый балл сам по себе не устанавливает диагноз.
- BE10-A03: Ни генерация, ни повтор, ни чтение результата не создают установленный диагноз или план. Качество альтернатив и опасных пропусков измерено отдельно.
