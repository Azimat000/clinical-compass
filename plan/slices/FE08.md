# FE08 — Редактирование и подтверждение решения врачом

Статус: PLANNED. Поручение: 27.10.2026. Одна сессия — один срез.
Зависимости: FE07. Общий план: `plan/frontend/README.md`.

## Работа

1. Внедрить в «План и решения» полный путь BE15: подготовить редакцию, просмотреть точный состав, изменить разрешённые поля, отдельно подтвердить или отклонить.
2. Перед применением показать отличия от действующего плана, точный препарат/силу/дозу/время/срок и рекомендации. Недопустимые автоматические переходы не предлагать; существующий ручной путь сохраняется.
3. Связать принятое решение с прежними календарём, рекомендациями, отметками и направлениями; показать квитанцию сервера и историю.

## Условия приёмки

- FE08-A01: Только отдельное явное подтверждение создаёт одно действие и меняет пациентский план; просмотр/предварительное сохранение/отклонение ничего не назначают.
- FE08-A02: Изменение данных между просмотром и подтверждением, CSRF, HEAD, двойной клик, две вкладки и повтор после перезапуска проверены; отклонённое/устаревшее не применяется.
- FE08-A03: Пациент получает ровно утверждённый состав, рекомендации и расписание; прежние отметки/состав/история сохранены. При ошибке врач видит сохранённую редакцию и причину отказа.

## Проверки и передача

Прочитать START_HERE/AGENTS, STATE, память решений/блокеров/источников/бюджета, последний принятый отчёт, этот файл и `plan/frontend/SESSION.md`. Проверить источниковые сроки и лимит перед модельными запросами.

```sh
python3 tools/design_skills.py check
python3 tools/validate_plan.py
python3 tools/session.py status
git diff --check
python3 tools/session.py start FE08
```

`start` выполняется один раз перед работой, остальные команды — до/после. Конкретные существующие целевые тесты выбрать по изменяемым модулям, записать команды и результаты в отчёте; браузерные действия и доказательства каждого Axx обязательны для изменённых экранов. Общий `make check` не запускать автоматически: прежнее поручение об отсрочке сохраняется.
