# retrieval-fixtures-1

144 собственных синтетических сценария: development60, control60, safety24.
Документы — искусственные технические примеры политики HAC, **не КР и не ГРЛС**.
Не загружать их в рабочий медицинский корпус. Страницы/цитаты существуют в
documents.json; fragments.json содержит точные координаты и обязательный
контекст, вопросы — достаточные комплекты или точные причины отказа.

Авторство Codex раскрыто; clinical_review=null. Независимой клинической
разметки и независимого слепого контроля нет. test_setup — условия стенда,
а не подсказки поиску; expected не передавать адаптеру приложения.

Семейства документов/случаев development/control/safety раздельные. Это
разделение собственных учебных документов, а не заявление о независимых
реальных КР. Для G02 рабочего корпуса требуется новая точная разметка до J04.

Пороги gates.json, состав/SHA/происхождение — evidence/S17J01/dataset-manifest.json;
доступ — access-log.json. Полный протокол: docs/validation/retrieval-protocol.md.
Изменения frozen-набора без новой версии запрещены. Builder отказывается
перезаписывать уже созданную папку. Набор создан до реализации поиска; поисковых
прогонов в S17J01 нет. Правильность оценщика проверяется отдельными microfixtures.
